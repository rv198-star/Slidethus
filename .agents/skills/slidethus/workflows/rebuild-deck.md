# Rebuild Deck Workflow

## Trigger

The user provides an existing PPTX/PDF/screenshots and wants a meaningful redesign or reconstruction.

## Steps

1. Preserve original files read-only.
2. Extract slide order, text, notes, assets, charts, layout, and visual tokens where possible.
3. Separate source facts from visual presentation.
4. Reconstruct the implicit brief, narrative, outline, and slide specs; mark assumptions.
5. Audit the existing deck before redesigning it.
6. Decide what to retain, remove, merge, split, or reorder.
7. Produce new Layout Plans and Visual System.
8. Render a new version; never overwrite the original unless explicitly authorized.
9. Compare old/new for content loss, factual drift, and intended improvements.
10. Deliver a change map and new files.

## Preserve

User-approved facts, required legal text, brand constraints, and intentional data definitions.
