# Improve Deck Workflow

## Trigger

Improve clarity, structure, visual quality, product maturity, or consistency without rebuilding everything.

## Steps

1. Define improvement objective and protected elements.
2. Audit first; do not redesign blindly.
3. Map issues to phases and affected slides.
4. Choose the earliest necessary intervention per issue.
5. Update artifacts and invalidate only dependent outputs.
6. Rerender affected pages.
7. Run local and cross-deck regression.
8. Deliver before/after change map and remaining issues.

Do not preserve a weak structure merely because the user asked for “beautification”; surface when a structural change is necessary.
