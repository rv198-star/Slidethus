# Extract Style Workflow

## Trigger

Derive a reusable Visual System from an existing deck, screenshots, or brand reference.

## Steps

1. Confirm rights and intended use.
2. Inspect representative pages, not only the cover.
3. Extract colors, typography, spacing, grid, shape, line, image, chart, icon, footer, and layout-diversity rules.
4. Separate brand rules from incidental slide-specific choices.
5. Record font availability and fallbacks.
6. Create `visual_system.json` and representative test pages.
7. Validate the system on multiple content types.

Do not copy third-party brand assets or fonts without permission.
