# Charcoal evidence and green phase bands

Consider for: Dense status, capability-gap or phased-change explanations.

## Borrowable grammar

- Use charcoal (#2C2C2C), light text and moss-to-mint accents; green phase bands and deep-green blocks create hierarchy.
- Pair directly labeled stacked bars with interpretations, or use a full-width maturity table when row comparison matters.
- A small section kicker and thin divider separate conclusion from evidence without a large navigation system.
- Use dot levels only for defined ordinal states; roadmap bands should preserve real sequence and timing.

## Adapt, do not inherit

The source describes only six sample pages. Discard its dark-only mandate, fixed three-card groups, quarter grids, block quotas and green-cover glow. Light or image-led contrast remains a design choice.
