# Friendly color fields and report modules

Consider for: Navigable longer explanations with coherent illustrations, parallel themes and tables.

## Borrowable grammar

- Use light green (#C3F0C9), deep green (#00634F), purple-black text and coordinated pink/lavender accents.
- Warm rounded type and restrained rounded modules can support parallel content without becoming a universal grid.
- Large color fields or flat illustration may mark section boundaries; dense tables should remain part of the same visual language.
- A low-profile navigation system can help a read-through report, while wide column gaps keep longer text legible.

## Adapt, do not inherit

Discard mandatory navigation, white-only data pages, topic-color assignments and bans on real photography. The source lacks a strong chart system; choose proper charts from data instead of multiplying number cards.
