# Pale-blue evidence and current-period focus

Consider for: Multi-period tables, changes and project metadata that need auditable reading.

## Borrowable grammar

- Use white, pale sky blue (#C2E6FF), electric blue (#007ACC) and navy comparisons.
- Highlight the current period as a continuous column; align numeric values and retain grouping rules and method notes.
- A bridge chart can connect opening and closing values to nearby causal explanations; paired bars should preserve shared scales.
- Use a light section marker and optional metadata rail; connectors must map to actual facts rather than decorate the page.

## Adapt, do not inherit

Discard obligatory arcs, fixed metadata counts, photo-only-on-dividers rules and all-light data-page rules. Header furniture must not crowd tables; pale highlights need sufficient text contrast.

## Nearby references

Compared with marine-blue-research, it emphasizes current-period tables and worksheet-like traceability over synthesis strips.
