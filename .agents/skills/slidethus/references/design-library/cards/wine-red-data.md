# Evidence-led lecture rhythm and wine-red transitions

Consider for: An extended explanation combining definitions, methods and quantitative evidence.

## Borrowable grammar

- Use clear argument–evidence–source relationships; wine-red (#820000) and restrained orange focus can carry section identity.
- A definition or quotation sits beside the figure it qualifies, not as an unrelated decorative card.
- Methods can use thin-line steps or loops, while dense tables keep definitions and source notes close.
- Section contrast can mark a real narrative change; reconcile shared type and chart semantics across any palette variants.

## Adapt, do not inherit

Discard source-specific color-section assignments, chart/box counts, observed slide fractions and body-image restrictions. A sectional reskin is not permission to change visual identity on every page.
