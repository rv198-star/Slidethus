# Capability Matrix

Declare one delivery level:

- D0 Full: research, assets, rendering, preview, review
- D1 Render-limited: artifacts complete; target format limited
- D2 Asset-limited: placeholders or user assets only
- D3 Research-limited: user sources only
- D4 Planning-only: brief through layout plans/wireframes
- D5 Blocked: core request cannot be honestly satisfied

Never call generated source code a verified output. Never call an unpreviewed PPTX visually passed. Record missing capabilities in Project State and Delivery Manifest.
