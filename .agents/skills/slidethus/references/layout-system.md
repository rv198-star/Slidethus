# Layout System

Choose layout from information relationships:

- `hero`: one dominant statement or visual
- `split`: two-sided comparison or before/after
- `process`: ordered steps or mechanism
- `timeline`: time-based development
- `matrix`: two-dimensional classification
- `architecture`: components, layers, or relationships
- `chart-story`: a data conclusion with supporting chart
- `case`: situation/action/result
- `full-bleed`: emotion, brand, or image-led page
- `bento`: modular summary or dashboard

Rules:

- Bento is not the default.
- Avoid the same family on three consecutive content slides without rationale.
- Use one primary visual focus.
- Use at least 20 logical pixels between independent regions unless the visual system explicitly overrides it.
- Keep reading order explicit.
- Fix content overload upstream before shrinking text.
- Store semantics in Slide Specs, geometry in Layout Plans, and styling in Visual System.
