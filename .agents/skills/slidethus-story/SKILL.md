# Slidethus Story — P3/P4

Read the [shared contract](../slidethus/references/shared-contract.md), [phase contracts](../slidethus/references/phase-contracts.md) and [artifact map](../slidethus/references/artifact-map.md). For host Create also read [host-create](../slidethus/references/host-create.md).

## Input and scope

An actionable Brief and orientation Evidence baseline; existing Narrative/Outline for revision. If these prerequisites are absent, identify the needed Brief/Research work. Do not invent evidence to produce a polished outline.

## Work

1. Define central thesis, audience shift, argument/proof sequence, section purposes, objections, exclusions and transitions. A table of contents is not a narrative.
2. Create Narrative Blueprint, then stable Deck Outline. Each slide needs a role, synthesized headline, takeaway, purpose, audience question, section and evidence refs. Headlines should state the page's proposition, not copy a paragraph from the source.
3. Fit sequence and density to live delivery/read-ahead needs. Give each page a distinct job. Vary roles when the argument calls for comparison, proof, mechanism, case or decision; do not manufacture variation or split every thought into a sparse page.
4. Reorder/split/merge/remove at the Outline layer before geometry. Let the runtime assign stable SEC/S IDs; preserve existing identities through admitted change operations.
5. Flag each page's remaining evidence and media/data needs for the targeted Research pass. A plausible story is not evidence readiness. If targeted research changes the premise, revise Narrative/Outline through the formal rework route before Plan.
6. In host Create, answer the current `narrative_blueprint` and `deck_outline` requests with bound proposals, resume and inspect admitted output. Do not copy deterministic defaults or write approved artifacts by hand. For changes use explicit `--revise-stage` as documented by the host entry.

## Exit

Narrative and Outline form a coherent argument within the Brief; stable slide objects have distinct messages and honest evidence refs. Record unresolved targeted gaps and the next handoff to Research, not premature permission to render. Stop after the outline for outline-only work; under the entry skill continue through targeted evidence and Plan.
