# 11｜Decisions and Non-goals

## 已确认决策

| ID | 决策 | 原因 |
|---|---|---|
| D-001 | Agentic Skill 优先，不先做独立 Agent 产品 | 复用宿主工具与模型，聚焦专业能力系统 |
| D-002 | 单一主编排器 | 降低上下文损耗和并行写冲突 |
| D-003 | 中间产物结构化并持久化 | 支持恢复、审计、局部返工和多后端 |
| D-004 | Slide Spec 与 Layout Plan 分离 | 区分“讲什么”和“放哪里” |
| D-005 | Visual System 与 Layout 分离 | 允许换风格而不改页面语义 |
| D-006 | Bento 是布局家族之一 | 防止模板化和表达失真 |
| D-007 | Hybrid PPTX 是 MVP 推荐目标 | 在视觉自由与编辑性之间平衡 |
| D-008 | 开放问题审计先于评分 | 避免评分锚定和平均分掩盖问题 |
| D-009 | Provider-neutral ports/adapters | 避免模型和供应商锁定 |
| D-010 | 逻辑画布默认 1280×720 | 与来源方法兼容且便于几何验证 |

## 暂未决定

- 最终开源许可证；
- 默认 LLM/search/image provider；
- PptxGenJS 与 OOXML 的长期边界；
- GUI 是否独立项目；
- Plugin 发布范围；
- 品牌名称与 Logo 视觉资产；
- 云端协作和多租户。

## 非目标

- 训练“最懂 PPT 的基础模型”；
- 承诺任何素材都一键生成无需修改；
- 完全替代专业演示设计师；
- 默认生成炫技动画；
- 复制某个商业 Agent 的私有实现；
- 把所有页面做成卡片；
- 在 v0.x 支持所有 Office 特性；
- 为追求完全可编辑牺牲所有视觉质量；
- 为追求视觉质量隐瞒不可编辑部分。
