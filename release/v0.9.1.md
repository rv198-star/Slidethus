# Slidethus v0.9.1 — Host Create 稳定性补丁

v0.9.1 修复 v0.9.0 实测中导致 Host Create 无法完成 PPTX 生成的跨阶段契约问题。本版本不重做既有视觉系统，也不宣称 v1.0 就绪。

## 修复

- 规划、预检与编译复用同一套文本容量合同，并按渲染后端使用真实文本框 inset。
- Artifact Tool 表格按内容分配列宽与行高，在启动导出前聚合报告容量问题。
- 深层返工、上游原子修订和 Art Direction Seed 直接修订使用一致的状态映射。
- Host candidate attempt 在开始、失败、超时和成功路径均留下结构化回执。
- doctor、preflight 与 render 复用同一 Artifact Tool runtime 解析结果。

## 验收

- Python 3.11：`400 passed, 44 skipped`；`validate_all.py`、`audit_package.py`、compileall、Ruff 和 diff 检查通过。
- 原失败案例在隔离副本中生成 8 页 PPTX/PDF，真实 PowerPoint 无修复提示，逐页未见裁切、碰撞或表格越界。
- 既有用户认可的 YU7 Host Create 案例由当前代码隔离重放：12 页真实 PowerPoint 检查通过；11 页程序渲染与原候选逐字节一致，唯一变化为 S-011 表格列宽改善。

## 能力边界

- 故障复现样本的视觉方向未获用户认可，因此只作为稳定性证据，不作为产品审美基线。
- 单个认可案例与包测试不等于任意主题都能自动得到高审美成品；每份正式 PPTX 仍需检查真实 PowerPoint 页面。
- 搜索、模型、图片生成、Artifact Tool 和 Office 预览仍属于宿主能力。
- M6.6 / v1.0 状态不因本补丁改变。

项目采用 Apache-2.0；第三方设计参考与案例素材遵循各自许可和权利说明。
