# Slidethus v0.9.0 — Pre-release

候选版本，**尚未完成新案例实测与真实 PowerPoint 全篇验收**。本次固定设计参考库能力，供后续测试；不声明审美提升已经验收，也不代表 v1.0 就绪。

## 变化

- 完整收录 44 套设计参考的通用适配卡，保留固定版本、MIT 许可、来源哈希和近似主题差异。
- 设计阶段自主判断是否参考：轻量索引 → 通常 1–3 张卡 → 必要时查看预览；允许不选、复用和局部借鉴，不要求用户点名主题。
- 参考决策沿既有 Taste 原生样板、ArtDirectionSeed、Specs/Layout、ArtDirectionPacket 传播；不新增行业分支、主题引擎或渲染路径。
- 示例成品归入 examples，README 保持案例图片优先。

## 安装

```bash
python -m pip install slidethus-0.9.0-py3-none-any.whl
slidethus plugin install-skill /absolute/path/to/project
```

Wheel 与资源 ZIP 包含九个技能、44 张适配卡、出处与许可；不包含上游图片、字体或原始手册。ZIP 不是独立运行程序或 Marketplace 一键安装声明。已有技能更新仍遵守安装冲突保护。
