# Slidethus v0.8.0

本次发布当前可用的 Agentic Presentation Engineering 技能套件与 Python 核心，不新增行业特例或额外优化。

## 主要能力

- `using-slidethus` 是总入口：从题目或材料开始、继续现有项目，或路由到局部任务；可一步到位，但不跳过证据、页面策划或用户指定的确认点。
- 七个阶段子技能覆盖需求、调研、叙事、页面规划、设计、渲染和审阅；`slidethus` 保留为兼容入口。全部由同一主 Agent 编排，复用既有结构化产物。
- 恢复并明确宿主设计入口：以宿主生成的真实设计为候选，接回页面规划和产出记录；不把确定性工程基线当作已确认的视觉设计。
- 内置固定版本 Taste Skill 与来源/许可证信息。Taste 驱动原生视觉样板后再转译到正式设计；模型、搜索、图像、审阅和渲染能力仍保持可替换。
- Wheel 和技能资源 ZIP 分发完整技能套件、共享参考、渲染脚本、Schema 与权利声明；保留旧安装位置读取兼容和冲突保护。

## 安装与使用

下载本 Release 的 Wheel，在 Python 3.11 环境中运行：

```bash
python -m pip install slidethus-0.8.0-py3-none-any.whl
slidethus plugin status
slidethus plugin install-skill /absolute/path/to/project
```

随后在该项目中使用 `$using-slidethus`。技能资源 ZIP 是可校验的资源分发包，不是替代 Python 核心的独立运行程序，也不声明为 Codex Marketplace 一键安装格式。

## 验证与边界

本轮只使用 Python 3.11，CI 也为单一 3.11 基线，不做多 Python 版本审计。精确测试结果与安装验证记录见仓库 `plans/v0.8.0-release.md`。

- 本地全量回归：366 passed、43 skipped；跳过不计为能力通过。Schema/工作区校验、21 项包审计、lint 均通过。
- 分发专项 7/7、Node 渲染器测试 5/5 通过；干净 Python 3.11 环境验证了 Wheel 安装与九个技能的完整物化。

- 搜索、模型、图片生成、Artifact Tool 和真实 Office 渲染依赖宿主能力，不由 Wheel 自动提供；缺失时应显式降级或停止，不能声称已完成。
- PPTX 文件可写出或通过结构校验，不等于视觉交付通过。正式 PPT 仍须检查真实目标 Office 渲染页面。
- 当前是 0.x 能力发布，M6.6 / v1.0 验收仍未完成；历史审计及兼容矩阵不是本轮跨平台或跨版本认证。
- 本轮不新增行业案例。后续真实任务继续验证样板到全篇的表现，不为单个案例添加代码特例。

项目代码采用 Apache-2.0；Taste 等第三方内容保留各自许可证。原始素材、字体及外部生成内容不因本项目许可证自动取得再许可。
