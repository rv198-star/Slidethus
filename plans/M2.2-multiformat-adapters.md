# M2.2 — Multi-format Source Adapters

## 1. Objective

- 用户价值：让 Slidethus 对 HTML、PDF、DOCX、PPTX、CSV/XLSX 和常见图片建立真实、可定位、可恢复的来源快照，而不是把“识别到格式”误报为“已经解析”。
- 本轮边界：只扩展 M2.1 Parser Registry 的 Production adapters、资源限额、格式风险、CLI/文档/测试；继续复用 Source Snapshot 与 Source Ledger lineage。
- 明确不做：OCR、宏执行、嵌入对象执行、公式计算、外链抓取、Web research、Evidence Engine、既有 deck 的视觉重建、图片内容理解。
- 退出条件：每种 admitted 格式有 golden fixture 与 locator；损坏、加密、空内容、超限、缺依赖和危险容器 fail closed；M2.1/MVP1 全量回归；Round A 无未修复 Critical/Major，Round B Submodule Gate PASS。

## 5. Quality and risk controls

- 输入字节只读；adapter 不执行宏、脚本、公式、链接或嵌入对象。
- OOXML 只接纳 `.docx/.pptx/.xlsx`，宏格式 `.docm/.pptm/.xlsm` 不落入普通 adapter。
- 表格与页面上限在迭代前检查；`max_chunks <= 9999` 对齐稳定 ID 合同。
- 图片只读取结构与有限 EXIF；GPS/作者等敏感字段记录风险，不默认输出原始值。
- PDF 图片页不调用 OCR，记录 warning 与 `partial`；全文件无可用文本则显式失败。
- Adapter 缺少可选依赖时返回可解释 capability error，不把来源标记为 unreadable 或 parsed。
- Snapshot key 自动包含扩展 limits 与 parser version；任何 adapter 行为变化需要 bump parser version。
