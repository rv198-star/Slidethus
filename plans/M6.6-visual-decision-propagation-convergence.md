# M6.6 Visual Decision Propagation and Scoped Calibration

Status: active
Started: 2026-08-30
Architecture: `docs/adr/ADR-0029-visual-decision-propagation-and-scoped-calibration.md`

## 1. Objective

- 用户价值：让视觉方向在页面载体和几何规划前生效，并在真实 Office 页面中可追溯地贯穿全篇；需要人工样板校准时，局部尝试不能污染全量发布状态。
- 本轮边界：只接入 Create；实现 Planning Policy、P5A representation、P5B binding、P6 executable grammar、IR/Office provenance、scoped Calibration Run/Decision 与 focused regression。
- 明确不做：不扩展行业/场景 corpus，不改变其他 workflow，不增加图片/图表配额，不把 Taste 写进领域 Schema 或 Renderer，不为三案例增加主题特判。
- 退出条件：本计划所列 Critical/Major 合同均实现并由负例证明；Create `off` 路径保持可用；`checkpoint` 路径局部输出不改变 catalog/Project State；full path 只有在 current approval 下运行；真实 PPTX/Office 页面通过复核。

## 4. Target artifact graph

```text
Brief + Narrative + Outline + G4 Asset Inventory
  → DesignPlanningPolicy (content-addressed)
  → Slide Specs / Block representation (selects one Policy)
  → Layout / Region representation_binding
  → ArtDirectionPacket (direction + policy resolution/deviation)
  → Visual System (only executable grammar)
  → Renderer IR (semantic/visual origins + rule effects)
  → full Render Manifest / Quality Report / G7–G9

checkpoint request only:
  current P5A/P5B/P6 facts
    → deterministic selector proof
    → ScopedProductionAttemptReport + current Office pages
    → CalibrationRun
    → CalibrationDecision
    → full Attempt
```

禁止的边：

- P5A/P5B 不读取 Packet、Visual System、Calibration、Render 或 Office；
- CalibrationRun 不引用未来 Decision；
- scoped attempt 不写 catalog Render/Quality/Delivery 或 completed G7–G9；
- Renderer 不读取 Taste/provider/Policy prose；
- fallback 不在 Renderer 临时改变 content type。

## 5. Contract design

### 5.1 DesignPlanningPolicy

Supporting Schema：`design_planning_policy.schema.json`。

最小事实：

- stable `DPP-*`、project/deck/status；
- provider execution identity/resource；
- `input_signature`；
- Brief/Narrative/Outline/Asset Manifest version/hash 与 asset inventory semantic hash；
- `policy_items[]`：targeted scope、strength、statement、machine constraint、source refs、fallback；
- warnings/assumptions；
- identity 不包含 wall-clock `generated_at`。

### 5.2 P5A representation

所有新 Create active non-spacer Block：

```text
representation:
  decision_id
  planning_status: planned
  function
  requirement: required | preferred | optional
  policy_refs[]
  rationale
  fallback_action: fail | substitute | omit | replan
```

`content_type`、Evidence 和 Asset refs 仍是唯一实际载体事实。G5A 从 current Policy 重算 hard constraints。

### 5.3 P5B binding

```text
representation_binding:
  decision_ref
  placement_fit: contain | cover | stretch | none
  asset_ref: optional
  asset_hash: optional
  focal_point: optional normalized x/y
```

不保存 authoritative fallback status。G5B 重算资产可用性、decision/ref/hash 与 fit 适用性。

### 5.4 Packet and Visual System

Packet 新增：

- `planning_policy` ref；
- `resolved_policy_items[]` with status and refs；
- `deviations[]` with pre-existing approval。

Visual System 新增唯一 `executable_rules[]`：

- stable rule ID；
- kind: object/geometry/deck_constraint；
- bounded selector；
- bounded declarations/effect fingerprint。

Packet 不拥有 rule IDs；Renderer 只消费 Visual System。

### 5.5 Renderer trace and review

- Region/decoration 拥有 stable `object_id`；
- semantic object trace：Block decision + Region + rules + assets/deviation；
- visual object trace：slide scope + rules；
- 允许一对多 object identity；
- G7 用 resolver 重算 applicable rules 和 expected properties，不接受空 effect 或伪 trace。

### 5.6 Scoped calibration

Supporting Schemas：

- `scoped_production_attempt_report.schema.json`；
- `calibration_run.schema.json`；
- `calibration_decision.schema.json`。

Workflow Request：

- `calibration_policy=off|checkpoint`；
- `calibration_decision_ref` 用于恢复 full run；
- 两者进入 request hash 与 execution signature/cache identity。

状态：

```text
selector blocked
  | scoped attempt terminated
  → awaiting_approval
  → approved | rejected | superseded
```

未批准时 Create 返回 blocked/awaiting approval，不把项目推进到 G7。批准事实绑定所有 P5A/P5B/P6 hashes、backend/font/renderer identity 和 Review Critical/Major=0。

### 5.7 Selector and Office provenance

- selector version、finite/bucketed feature dictionary、stable tie-break；
- candidate features、coverage targets、selected/unselected rationale、uncovered features；
- selected=all slides 时提升 full attempt；
- Office page 绑定 attempt ID、PPTX path/hash、renderer identity、ordinal、slide ID；
- Office 缺页/重复/旧 PPTX/hash 漂移即 blocked；SVG 仅 comparison。

## 6. Gate and stop matrix

| 边界 | 独立检查 | 失败动作 |
|---|---|---|
| Policy admission | Schema/provider/input signature/G4 asset inventory/hard constraint grammar | capability block 或新 Policy |
| G5A | unique Policy ref；所有 non-spacer planned；hard constraints；Evidence/Asset/fallback | P5A replan |
| G5B | decision ref；Block→Region；placement asset/hash/fit；availability 重算 | P5B repair 或 P5A replan |
| G6 | Packet 合法解析 Policy；deviation 已授权；Visual System 是唯一 grammar | P6 repair |
| scoped attempt | selector proof；terminal scope；non-catalog；Office provenance | blocked/new attempt |
| checkpoint | Review Critical/Major=0；explicit current Decision | awaiting/rejected/superseded |
| G7 | full scope；rule/effect/IR/backend parity 重算 | P7 或最早上游 |
| G8/G9 | current full Office/Review；checkpoint Decision current；editability/降级披露 | draft，不 release |

## 7. Validation set

本轮只复用 FDE、中国珠宝、酒店香薰。它们只做 E2E Office/user acceptance；CI 生产不变量使用 opaque IDs、冻结 provider proposals 与结构性/metamorphic 负例。

必要负例：

1. hard item 无目标或机器 constraint；
2. legacy/unplanned Block；
3. asset missing，但 Region 自报 ready（该字段不应成为权威）；
4. Packet 自报 resolved，实际反转 hard constraint；
5. 统一 trace ID 但 effect 不符；
6. applicable rule 改变但 IR effect 不变；
7. 不适用/语义等价 rule 不应误报；
8. selector 顺序变化仍选择一致；
9. uncovered feature blocked；
10. scoped attempt 尝试修改 catalog/Project State；
11. Review 有 Critical/Major 或 approval stale；
12. Office 缺页/重复/旧 PPTX/hash 漂移；
13. 主题文本替换或 stable ID remap 后 deterministic behavior 结构等价；
14. production code/schema logic 出现案例词、固定 slide ID 或 fixture-derived routing。

## 9. Quality and risk controls

- 受影响 Schema：Policy、Slide Specs、Layout Plans、Packet、Visual System、Renderer IR、Visual Review、Scoped Attempt、Calibration Run/Decision；canonical 与 packaged mirrors 同步。
- 受影响 Gate：G5A、G5B、G6、G7、G8、G9；Project State phase enum 不增加。
- 回归范围：Create/M3/M4/M5/M6 runtime；其他 workflow 行为不得改变。
- Migration：optional Schema + Create capability Gate；不得自动生成历史 rationale。
- Provider：Taste 为默认可替换 adapter；resource hash/license 继续 fail closed。
- Anti-overfit：案例词只允许 tests/evaluation/audit/docs；production logic 使用结构化 features/constraints。
- Release：实现/测试 PASS 不替代真实 Office 页面和用户视觉接受。
