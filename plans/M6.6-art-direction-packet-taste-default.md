# M6.6 Art Direction Packet + Taste Default Provider

## 1. Objective

- 用户价值：Slidethus 默认具备可开箱使用的高质量艺术指导基础，同时允许未来替换为其他模型、Skill、人工或企业设计系统 provider。
- 本轮边界：引入 schema-backed `ArtDirectionPacket` 运行事实、provider-neutral 协议、内置 Taste 默认 provider、Visual System 消费链路、发行与版权清单。
- 明确不做：不让 Taste 直接控制 PPTX/SVG 渲染器；不把网页交互动效规则机械移植到幻灯片；不声称仅凭 Skill 已完成 Office 视觉验收。
- 退出条件：默认 provider 可离线生成并冻结 Packet；Visual System 绑定 Packet hash；wheel/Plugin 携带固定版本 Taste Skill 和 MIT 许可；相关测试与项目规定检查通过。

## 2. Current state

- 当前 HEAD / 工作区状态：`af88bed`；M6.6 视觉质量修复工作区已有未提交修改，本计划只做可区分的架构、契约、发行与测试增量。
- 已存在能力：P6 `VisualSystemService`、确定性 Artifact Runtime、PPTX/SVG render backends、Plugin/wheel 分发、第三方权利策略与 SPDX SBOM。
- 已知缺口：Visual System 目前由硬编码确定性样式直接生成；没有 provider-neutral 艺术指导契约；Taste 未被版本固定或随发行包分发。
- 基线测试：本轮开始前未重跑全量测试；TASKS 当前明确为 M6.6 release reopen / DO NOT RELEASE。

## 5. Quality and risk controls

- 受影响 Schema：新增 `art_direction_packet.schema.json`；扩展 `visual_system.schema.json`、Plugin Manifest 和 rights policy。
- 受影响 Gate：G6 增加 Packet 文件、hash、provider identity 和当前 Visual System 引用一致性检查；G5B 不变。
- 回归范围：Visual System 幂等性、G6 stale detection、Renderer IR 输入、Skill/Plugin/wheel 物料化、SBOM 与 license audit。
- 降级路径：显式注入其他 `ArtDirectionProvider`；默认 Taste 资源缺失或 hash 漂移时 fail closed，不静默冒充 Taste；已有 legacy MVP theme 的兼容例外不扩大。
- 安全/来源/版权风险：Taste 为 MIT，必须随复制件保留版权与许可文本；Slidethus 的适配代码仍为 Apache-2.0，不能把上游内容标记为项目自有。
