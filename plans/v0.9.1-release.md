# v0.9.1 稳定性补丁发布收敛

## 1. Objective

- 用户价值：把已经完成修复和真实回归的 Host Create 稳定性改动收成可安装、可核验的补丁版本。
- 本轮边界：版本、发布说明、单 Python 3.11 分发验证、本地发布附件、提交、标签和 GitHub Release；Issue #2 按稳定性范围关闭。
- 明确不做：不重做视觉系统，不新增案例，不发布 v1.0，不上传 PyPI。
- 退出条件：版本一致，Wheel/Plugin ZIP 可构建并在仓库外验证，附件哈希可核对，工作区差异无格式错误。
