# M6.6 Preview Hardening — Systemic Root Fixes

## 1. Objective

- 用户价值：修复 Round 4 Review Synthesis 已归因的五个通用质量缺陷，使同一 Preview case 能在不改变 Source/Brief 的情况下重新通过生成与渲染质量底线。
- 本轮边界：P7 字体 glyph/script coverage、P7 decoration/layout geometry、P4 headline proposition、P4 structural-slide visible copy、P5A action-block responsibility/deduplication；focused regression；同案完整 Production Attempt；Attempt 结束后的九阶段 SAR 与 SYN；随后才进入 M6.6 Release Gate。
- 明确不做：不重开 M6.1–M6.5；不修改 Preview Source/Brief；不修 `project_identity_and_presentation_title_are_conflated` 这个 case-local contract；不在 Production Attempt 中途 Review/Repair；不增加页号、主题、原句或语言名称特判；不把 Minor/Suggestion 审美偏好规则化。
- 退出条件：五个 systemic candidates 均有抽象 owning invariant 与 unrelated fixture；focused/owning regression 通过；同案 Attempt 完整结束；九个 SAR 与一个 SYN 完成；无 Critical、无 Major systemic candidate；M2–M5 与 M6.3–M6.5 Gate 保持 PASS；release validator、可重复构建与 package audit 通过后才允许 v1.0 Release decision。

## 5. Quality and risk controls

- 受影响 Schema：优先不改 Schema；若必须新增 coverage/decoration facts，则 canonical 与 packaged mirrors 同步并验证 Draft 2020-12。
- 受影响 Gate：P4/G4、P5A/G5A、P7/G7、M4 Exit、M5 deterministic review、M6.6 Release Gate。
- 回归范围：font/assets/preflight、render compile/backends、outline/spec planning/review、workflow application、M2–M5 Exit、M6.3–M6.5、Node renderer、package audit。
- 降级路径：无法证明 glyph coverage 时明确 capability/error hard block；不接受 family name 作为兼容性证据。
- 安全/来源/版权风险：不下载或打包字体；只读取已解析 font file 的 cmap/Fontconfig charset；Preview Source 保持只读。
