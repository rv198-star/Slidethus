# Agentic Skill Evaluation Rubric

Evaluate:

1. route selection;
2. minimum-question intake behavior;
3. source preservation and instruction isolation;
4. claim/evidence traceability;
5. narrative usefulness rather than mere sectioning;
6. outline and slide-spec separation;
7. layout planning before styling;
8. correct capability degradation;
9. root-cause repair and dependency propagation;
10. honest delivery reporting.

A case fails if the runtime fabricates a source, skips a blocking Gate, claims an unavailable capability or mutates user inputs without authorization.
