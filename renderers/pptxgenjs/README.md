# PptxGenJS / Hybrid PPTX Backend — Planned

Recommended target: Hybrid PPTX.

- native PowerPoint text, simple shapes, tables and charts where editability matters;
- SVG for complex diagrams and stable vector visuals;
- raster images only for photographic or generative assets;
- explicit editability level per delivery;
- render-to-image regression in PowerPoint/LibreOffice-compatible environments.

This directory defines a boundary only. No production Node package is included in M0, avoiding an untested placeholder that could be mistaken for working export.
