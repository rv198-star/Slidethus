## Root fixes exposed during evaluation

The Production corpus exposed one operational-control defect: an in-flight `started` Workflow Event was treated as workspace corruption before its terminal event existed. M6.2 was root-fixed so one valid open attempt is legal during execution and is recovered on the next exclusive lease if orphaned. Invalid/tampered event sequences still fail closed.

## Capability boundary

M6.4 does not claim:

- production semantic/visual model provider quality;
- every OS/Office combination is tested;
- Quick mode equals Production certification;
- v1.0 release readiness.

The compatibility matrix records verified, optional, degraded and unverified states explicitly.
