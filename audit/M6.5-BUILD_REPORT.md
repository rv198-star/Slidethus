## Distribution policy

Default Slidethus wheel/Plugin release contains project-owned code/docs/Skill/schemas/renderer source and release-compliance files. It intentionally does not vendor:

- `source_material/`;
- user/private workspace inputs;
- downloaded Node `node_modules`;
- Python dependency wheels;
- font binaries;
- model binaries/weights;
- unlicensed brand/visual assets;
- prepared renderer caches.

Redistributing a container, prepared cache or other environment that includes third-party binaries requires its own exact notices and artifact-specific SBOM.
