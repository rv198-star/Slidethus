### 5.2 Promoted systemic candidates

#### A. P4 — headline semantic compression

Pattern: `headline_semantic_compression_stops_at_clause_selection`

Several content slides still use the first usable Evidence/source clause as the headline. Gross paragraph copying is fixed, but a length-bounded source clause is still not the same as a synthesized audience-facing proposition.

Root principle:

> Headline generation must derive the page proposition from the page job, not merely select a shorter source clause.

#### B. P4 — planner meta-language on structural slides

Pattern: `structural_slides_serialize_planning_meta_copy`

Example symptom: the section slide visibly says it is “entering” a section and “will answer” a planning question.

Root principle:

> Planner purpose/transition/audience-question metadata stays orchestration truth; structural slides emit audience-facing framing copy or intentionally minimal structure.

#### C. P5A — duplicated action responsibility

Pattern: `action_blocks_repeat_the_primary_cta`

The final action slide creates one body block with the CTA and another list whose first item repeats the same CTA.

Root principle:

> Action/decision blocks must have distinct responsibilities (decision, owner, timing, checkpoint, success condition) and deduplicate the primary CTA.

#### D. P7 — **Critical release blocker: invalid font fallback acceptance**

Pattern: `font_fallback_ignores_required_script_coverage`

The zh-CN Visual System requests `Noto Sans CJK SC`. Round 4 preflight substitutes:

`Noto Sans CJK SC -> DejaVu Sans (fontconfig_best_match)`

Resolved file:

`/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf`

`fc-query` confirms this file has no CJK U+4E00-range coverage, yet M4 reports ready and Renderer IR uses DejaVu Sans.

Root principle:

> A substitute font is admissible only if it covers the scripts/glyphs required by the deck. Fontconfig family resolution alone is not evidence of render compatibility.

Required direction: generic script/glyph coverage validation, not a hard-coded Chinese font list.

#### E. P7 — renderer decoration ignores layout geometry

Pattern: `render_decorations_ignore_layout_geometry`

`RenderCompileService._decorations()` places process/timeline connector line at fixed `y=580`.

Round 4 S-007 second-row process regions span approximately `y=538.08..660`, so the fixed line intersects content regions after P5B has already produced a valid layout.

Root principle:

> Decorations/connectors added after layout must derive from region anchors or participate in collision validation; fixed decorative coordinates cannot invalidate approved geometry.
