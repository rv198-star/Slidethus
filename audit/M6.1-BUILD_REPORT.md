**M6.1 Submodule Gate: PASS.**

## Implemented workflows

- **Create** — new/stage-0 workspace + user sources/Brief → M3 → M4 → M5/G8.
- **Rebuild** — PPTX/PDF/image reference ingested read-only into a separate workspace; original bytes verified unchanged.
- **Audit** — M5 review with `auto_repair=False`; immutable review/runtime facts may be added while frozen semantic/render refs remain unchanged.
- **Improve** — audit first, then only M5-admitted repair when automatic repair is enabled; clean decks are idempotent no-op improvements.
- **Revise** — explicit stable slide IDs + structured Outline fields → Change Report → Specs/Evidence/Layout regeneration → M4 → M5 regression/G8.
- **Extract Style** — deterministic PPTX token extraction into a schema-valid Visual System candidate; font/media bytes are not copied.

## Upstream root fixes exposed by M6

M6 did not rewrite frozen M2–M5 contracts. It did expose and root-fix four contradictions required for legitimate product workflows:

1. M3 Planning Review no longer labels unsupported repair codes as automatic.
2. M3 ready reports accept Minor-only Planning Review issues while still requiring zero Critical/Major.
3. historical invalidated Render/Quality/M5 facts remain verifiable without blocking upstream rework; active G7/G8 still require current facts.
4. M5 `auto_repair=False` now disables semantic/visual Repair Execution as well as deterministic auto-repair.
