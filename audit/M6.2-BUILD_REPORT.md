# M6.2 Build Report — Operational Controls

## Outcome

M6.2 adds one provider-neutral operational control plane above the M6.1 Workflow Runtime. It controls execution/reuse/recovery but does not create semantic, planning, rendering or review truth.

**M6.2 Submodule Gate: PASS.**

## Delivered

### Attempt/event lifecycle

- stable `WAT-*` attempt identity;
- immutable `WEV-*` started/terminal/recovered events;
- workspace validation and tamper detection;
- orphan attempt recovery after exclusive lease acquisition;
- same-request/same-signature resume admission for interrupted Create/Rebuild.

### Workflow Operation facts

- immutable `WOP-*` reports;
- WOP → WFR lineage;
- WOP → WEV attempt/terminal lineage;
- recomputed action/output/change metrics;
- cache status, duration, input/update metrics and provider-cost measurement state.

### Cache policy

Cache reuse requires all of:

1. valid WOP/WFR/WEV lineage;
2. matching request hash;
3. matching execution signature;
4. age within `max_cache_age_seconds`;
5. current `artifacts_after` bindings;
6. valid referenced output hashes.

`max_cache_age_seconds=0` disables cache reuse.

### Budgets

Operational limits now cover:

- source-file bytes plus canonical structured request payload bytes;
- target slide-update count;
- wall time;
- optional host-measured provider cost;
- cache age.

Budget exhaustion is a structured blocked workflow outcome where the runtime can safely publish one.

### Concurrency

`WorkflowLease` provides one non-blocking exclusive workspace mutator lease. Recovery runs only after that lease is acquired, so one active process cannot be mistaken for an orphan attempt.

## Root fixes discovered by M6.2

Round A identified and fixed:

- missing durable attempt lifecycle;
- recovery bookkeeping without Create/Rebuild resume admission;
- unvalidated WOP cache admission;
- self-reported operational metrics;
- exception-only wall/cost budgets;
- structured request bytes excluded from resource budget;
- missing cache TTL;
- malformed timestamp cache robustness.

No waiver was used.
