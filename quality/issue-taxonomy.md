# Issue Taxonomy

## Severity

- **Critical**: wrong or unsafe factual conclusion, corrupt/unopenable deliverable, material privacy/security/license breach, or complete failure of user objective.
- **Major**: broken story, missing required evidence, unreadable key slide, pervasive visual inconsistency, or missing requested output.
- **Minor**: local clarity, spacing, phrasing, alignment or metadata defect that does not invalidate the deck.
- **Suggestion**: optional improvement with no current requirement breach.

## Root phase categories

P0 brief; P1 source; P2 evidence; P3 narrative; P4 outline; P5A slide semantics; P5B layout; P6 visual system; P7 render/export; P8 review/regression; P9 delivery.

Always file the issue against the earliest responsible phase, while recording affected downstream slides/blocks/regions.
