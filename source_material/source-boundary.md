# Source Boundary

## 来源直接支持

原素材直接支持以下方法论：

- 先澄清需求，而不是从主题立即套模板；
- 研究和资料搜集是大纲与页面内容的基础；
- 以“数字便利贴”形式管理页面级大纲；
- 在最终视觉设计前建立页面策划稿；
- 卡片/Bento Grid 是模型较容易掌握的一种布局语言；
- 用 SVG 作为整页视觉输出的一种实现路径。

## Slidethus 的独立设计

以下内容由本基础包补充，不能冒充原作者已公开实现：

- 证据账本和逐声明可追溯；
- 多阶段 JSON Schema 与状态机；
- provider-neutral 端口和多渲染后端；
- Editability Level、Delivery Level 和能力降级；
- 开放问题审计 → 修复 → 维度评分 → Gate 的双层质量机制；
- 原子写入、哈希、跨产物引用校验和回归测试；
- 单一主编排器与受限子代理策略。

## 使用规则

- 引用来源原话、原提示词或例图时，必须保留来源身份；
- 浏览器原始 HTML 因含会话/页面元数据而不进入项目发布包；
- 改写后的生产提示词放在 `prompts/production/`，不得覆盖 `source-preserved/`；
- 来源没有支持的能力，应标记为 Slidethus 设计、推论或待实现项；
- 不得把商业项目的未公开实现细节当作已知事实。
