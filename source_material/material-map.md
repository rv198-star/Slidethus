# Slidethus｜PPT Agent 素材拆解

## 阅读结论

可以完整读懂。已从用户提供的网页文件中定位并抽取：

- 1 篇主帖正文；
- 4 个方法论章节；
- 3 段原始提示词；
- 19 个有效例图/动图引用；
- 1 条完整产品流程；
- 1 份面向 Slidethus 的吸收建议与工程缺口清单。

## 核心流程

**需求调研 → 资料搜集 → 大纲策划 → 生成策划稿 → 生成设计稿 → 输出 SVG / 导入 PPT**

## 本素材最关键的贡献

不是“Bento Grid”本身，而是把专业 PPT 团队的工作拆成了可交给 Agent 的中间阶段，尤其是将 **页面策划稿** 放在内容与最终视觉之间。

## 文件说明

- `01_原文主帖_清洗版.md`：清洗后的原作者主帖。
- `02_工作流与核心思路.md`：只基于原文的结构化摘要。
- `03_提示词/`：3 段提示词分别保存。
- `04_例图/例图在线画廊.html`：联网打开后加载全部例图；包含 3 个 GIF。
- `04_例图/例图索引.csv`：图片编号、阶段、用途、本地引用和原始链接。
- `05_Slidethus_评估/`：模型分析，已与原文素材分开。

## 资源完整性说明

上传的 HTML 没有携带浏览器保存时生成的同名 `_files` 目录，因此本地包内没有原图二进制。原文保留了 16 张静态图的原始 CDN 链接，另外 3 个 GIF 链接可从帖子资源路径恢复；在线画廊会直接加载这些原始资源。
